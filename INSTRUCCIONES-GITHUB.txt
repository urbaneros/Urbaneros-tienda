URBANEROS — CATÁLOGO PÚBLICO CON ADMINISTRACIÓN PRIVADA

Esta carpeta contiene la web pública. Los visitantes ven los productos; solamente la cuenta autorizada en Supabase puede iniciar sesión, cargar fotos y administrar el catálogo. GitHub Pages publica la página; Supabase guarda los productos, las fotos y los permisos.

ANTES DE PUBLICAR
1. Conecta esta página a tu proyecto Supabase en supabase-config.js con Project URL y Publishable key. Nunca pongas una Secret key en este archivo.
2. En Supabase, abre SQL Editor > New query. Ejecuta el archivo privado urbaneros-admin-setup-privado.sql que te preparé. Ya está configurado para el correo administrador que indicaste. No subas ese archivo SQL al repositorio público.
3. En Supabase Authentication, desactiva los registros públicos de usuarios. Deja creado solo tu usuario administrador. No agregues más usuarios.
4. Usa solamente la clave Publishable (sb_publishable_...). No copies claves Secret (sb_secret_...) al código de la tienda.

DESTACADOS Y OFERTAS
La configuración de Supabase que ya habilitó el destacado y las categorías también sirve para esta versión; no hace falta volver a ejecutar SQL. Desde el panel privado puedes marcar varios productos como destacados. Los visitantes pasan entre ellos con las flechas o deslizando en el celular. Para mostrar OFERTA en cualquier producto, completa el precio actual y el precio anterior, aunque no lo marques como destacado.

PRODUCTOS AGOTADOS
Para esta función nueva, ejecuta una sola vez el archivo privado urbaneros-stock-agotado-migracion-privada.sql en Supabase > SQL Editor > New query. No subas ese archivo al repositorio público. Los productos existentes siguen disponibles. Después de actualizar la página, entra al panel de administración y edita un producto. Al marcar “Marcar como agotado”, el estado se guarda inmediatamente. Al desmarcarlo, vuelve a estar disponible. En un producto nuevo, el estado se guarda al pulsar “Guardar producto”.

FOTOS Y CATEGORÍAS
Las fotos nuevas se reducen automáticamente antes de subirlas si el archivo resultante queda claramente más liviano. Las 26 fotos actuales de “CAMISETAS FÚTBOL” ya están en formato WebP y pesan menos de 190 KB cada una, así que no necesitan volver a comprimirse. Para revisar las demás, entra al panel privado y usa “Optimizar fotos existentes” con “Todo el catálogo” seleccionado. Las fotos que ya son livianas no se cambian. Las originales permanecen en Supabase como respaldo, aunque el catálogo use las versiones reducidas. Puedes detener el proceso y retomarlo más tarde.
Las categorías del encabezado se actualizan desde Supabase. En el celular, para cambiar el nombre de una categoría toca “Editar”, escribe el nombre en el formulario y toca “Guardar”.

PUBLICAR EN GITHUB
1. No hace falta ejecutar ningún SQL nuevo para esta actualización.
2. Sube el contenido de esta carpeta a la raíz del repositorio público Urbaneros-tienda, reemplazando los archivos anteriores. No subas el ZIP cerrado ni archivos SQL privados.
3. Espera a que GitHub Pages termine de publicar y actualiza la página en el navegador.

ENTRAR A ADMINISTRAR
1. Abre la dirección pública de la tienda y añade #admin al final (por ejemplo, https://usuario.github.io/urbaneros-tienda/#admin).
2. Inicia sesión con el correo y la contraseña del usuario que creaste en Supabase.
3. Agrega el nombre, categoría, descripción, precio opcional y hasta 3 fotos. Guarda; el producto aparece en el catálogo público.
4. Cuando la sesión esté iniciada, el botón “Administrar tienda” aparecerá en la cabecera. Los visitantes no lo verán.

SEGURIDAD
- El catálogo es público y los productos/fotos son visibles para cualquiera que visite la página.
- La base de datos autoriza leer los productos sin iniciar sesión, pero solo la cuenta autorizada puede agregarlos, cambiarlos, quitarlos o subir fotos.
- No subas contraseñas, claves Secret ni urbaneros-admin-setup.sql al repositorio público.
